# TPM self-check, copy to rewrite

Every user-facing string in the `/tpm-self-check` tool, in one place, for webs to put in her
own voice. All of it is my placeholder draft.

**How to use this:** edit the "Your version" column (or strike the draft and write under it).
Keep the **id** so the rewrite maps straight back to the code. Leave a row blank to keep the
draft as-is. When you are done, hand it back and I apply every change by id.

Voice reminders for this pass: plain words before jargon, complete sentences, the Oxford
comma, no em dashes, no false contrasts (state the positive, skip the ", not X"), no
self-certifying virtue words.

## 3. The five delivery skills: names and definitions

| id | Name (draft) | Definition (draft) | Your version |
|---|---|---|---|
| change | Change control | When the scope of the work shifts, you make the tradeoff clear and get it agreed before the team just absorbs it. | |
| risk | Risk management | You spot what could derail the work early and act on it, rather than reacting once it has already hit. | |
| financial | Financial management | You track what the work costs and what the budget allows, and keep the two in line. | |
| reporting | Stakeholder reporting | You keep the people who care about the work informed of the true state of it, the good and the bad. | |
| value | Value articulation | You can explain the worth of the work in the terms the client actually cares about. | |

Short labels on the radar: change → Change, risk → Risk, financial → Financial, reporting →
Reporting, value → Value. Change any you dislike.

## 4. Growth guidance (the "to grow this, do this" line for the focus competency)

| id | Current draft | Your version |
|---|---|---|
| conflict | Name the disagreement out loud early, and separate the decision from the person. Rehearse the pushback before the meeting. | |
| collab | Before grinding solo, ask who holds the missing piece and bring them in. Say plainly when a call is yours to make versus the group’s. | |
| comm | Write every update as three lines: what is true, what it means, what is next. Then check they actually got those three. | |
| goals | Turn a fuzzy ask into one specific, measurable target before work starts, and give feedback against it while there is still time to act. | |
| coord | Map roles, handoffs, and sequence at the start, and keep the plan visible so you set coordination up front instead of scrambling for it later. | |
