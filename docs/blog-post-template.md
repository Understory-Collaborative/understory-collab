# Blog post template

This is the source for the `_TEMPLATE — make a copy` Google Doc that lives in the
Drafts folder. Authors start a post by copying that Doc, not by touching this file.

A post needs: a **title** (a Heading 1 in the Doc), a **slug**, an **excerpt**, and a
**body**. A **subtitle**, a **cover image**, a **category**, and **tags** are optional
but recommended.

---

## What the author sees in the template Doc

> **How to use this template** _(delete this note in your copy)_
> Right-click this Doc → **Make a copy**. Name the copy anything you like; the Doc
> name is only for finding it in Drive. Fill in the fields below, write your post,
> then leave the copy in **Drafts** to preview it or move it to **Published** to go live.
>
> _[Paste your cover image here, at the very top. The first image in the doc becomes
> the post's cover, shown behind the title at the top of the page.]_
>
> _[Your post title, styled as **Heading 1**.]_
>
> _[Optional subtitle, styled as **Heading 2**, directly under the title.]_
>
> **Slug:** the-web-address-for-this-post (lowercase words joined by hyphens)
>
> **Excerpt:** One or two sentences summarizing the post. Aim for under 155
> characters. This shows on the blog list and as the Google search description.
>
> **Category:** One short label, for example Delivery. Shows as a badge.
>
> **Tags:** comma, separated, keywords
>
> Write your post here. Use **Heading 2** and **Heading 3** for sections, **bold**,
> _italics_, and links as normal, and drag images straight into the doc.
>
> For a Q&A post, start the reader's question with `Q:` and your answer with `A:`.
> The page shows them as a labeled question card and answer. A short last line in the
> question with no end punctuation is shown as the reader's sign-off.
>
> ---
>
> **To preview:** keep your copy in **Drafts**, then run the sync (Actions → Blog
> sync from Google Drive → Run workflow). Your preview link is ready a minute later.
> **To publish:** move your copy into **Published**. It goes live within a day, or
> right away if you run the sync.

## How each field maps to the post

| In the Doc | Becomes |
|---|---|
| First Heading 1 (or a Title-style line) | Post title; the Doc name is the fallback |
| Heading 2 directly under the title (or a Subtitle-style line) | Subtitle |
| `Slug:` line | Web address, `/blog/<slug>`; the title is the fallback |
| First image (before the first section heading) | Cover image, behind the title |
| `Excerpt:` line | Blog-list blurb + SEO description |
| `Category:` line | Category badge |
| `Tags:` line | Tag chips |
| `Q:` and `A:` paragraphs | Question card and answer section |
| Everything else | Post body |
| _(automatic)_ | Date = Doc creation day; author = Doc owner |
