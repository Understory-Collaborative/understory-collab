# Statement of Work (SOW)

One project, run under a signed Master Services Agreement (see
`master-services-agreement.md`). It names the deliverables, price, dates, and acceptance for
that engagement. Sign one SOW per project. The MSA is signed once; each new project needs
only a new SOW.

> **This is a template, not legal advice.** Fill in every `{{PLACEHOLDER}}` before sending.
> A SOW inherits its terms from the MSA. Only override an MSA term here if you mean to, and
> say so explicitly in section 12.
